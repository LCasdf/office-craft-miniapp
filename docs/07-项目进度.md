## 5. M1 切片说明（截至 2026-09-07）

**工具：** 图片转 PDF / Word 转 PDF / PDF 压缩 / PDF 合并（见历史条目）。

**任务闭环**
- 创建预扣、成功实扣、失败/取消/超时返还；safety 实扣  
- `POST /v1/tasks/{id}/retry`（新 Idempotency-Key，≤2 次，非 safety）  
- `GET /v1/tasks/{id}/download` → 过期 `40016`  
- Beat：`cleanup_ttl` / `check_alerts` / **`sweep_timeouts`（60s）**

**联调：** 改过 Worker/Beat 后须重启对应进程。完整命令见 [05](./05-启动步骤.md)。
